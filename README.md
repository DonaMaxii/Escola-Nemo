Projeto de Software: Escola de Natação Nemo.

Projeto de banco de dados, em Access, SQL e VBA, realizado para a disciplina de Programação em Microinformática, ministrada pelo Prof. Humberto Luiz de Toledo, pela Fatec de São Caetano do Sul - Brasil.

Desenvolvido por Jessica Soares (https://github.com/JeehSilphis) e Maxine "DonaMaxii" Santos.

## Código-fonte

O banco `projeto_escola_natacao.accdb` guarda as tabelas, formulários, relatórios, consultas e o código VBA. Como o GitHub não consegue ler o conteúdo de um arquivo `.accdb`, o código também foi exportado em arquivos de texto:

- `codigo/` — módulos VBA (`.bas`) e o código dos formulários e relatórios (`.cls`)
- `consultas/` — SQL das consultas salvas no banco

O `.accdb` continua sendo a versão principal do projeto; as pastas acima são uma cópia para leitura. Se o código for alterado no Access, exporte os módulos novamente (no editor do VBA: botão direito no módulo → *Exportar arquivo*).
